This website does not ask visitors to create an account. Favourite pairs and recent conversion history are stored locally in the visitor's browser using local storage. How to use the converter

  1. Enter any amount.
  2. Search by country, currency name or three-letter currency code.
  3. Select the currency from the dropdown list.
  4. Press Convert currency to see the estimated result.
  5. Use the star button to save a favourite pair.

Important: Rates may be delayed and can differ from bank, card, cash-exchange and money-transfer rates. Check the final rate and fees with your provider before making a transaction.
