PUBLISH FREE USING GITHUB PAGES
1. Extract this ZIP on your computer.
2. Sign in to GitHub and create a PUBLIC repository named pranab-currency-converter-pro.
3. Upload index.html to the repository's main/root folder. You can also upload this README.
4. Open repository Settings > Pages.
5. Under Build and deployment, select "Deploy from a branch".
6. Select branch "main" and folder "/ (root)", then Save.
7. Wait for GitHub Pages to deploy. Your public website URL will appear in Settings > Pages.

IMPORTANT SETUP BEFORE PUBLIC LAUNCH
- Replace the placeholder contact email in index.html with an email address you control.
- Review and update the Privacy Policy to match the services you actually use.
- Ad placeholders are NOT live ads. Real AdSense ads require an AdSense account, site review/approval, and your own publisher code. Approval is not guaranteed. Never click your own ads or encourage anyone else to click them.
- The main exchange-rate API and historical chart API are third-party services. Historical chart coverage is more limited than current-rate coverage; some currency pairs will show an unavailable message.
- Conversion history and favourites are stored only in each visitor's own browser local storage. They are not synced across devices.
- Exchange rates are estimates and may differ from bank, card, cash exchange or transfer-provider rates and fees.
- This is a static website; no server or paid hosting is required.
